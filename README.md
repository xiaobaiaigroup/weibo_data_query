# 微博信息批量查询工具

## 1. 工具用途

本工具用于公司内部授权范围内，批量整理少量微博链接的公开信息。业务同事可以把多条微博链接粘贴进去，工具会按输入顺序查询并生成表格，方便复制到 Excel / WPS。

可查询字段：

- 发布日期
- 发布内容
- 账号名称
- 发布链接
- 转发数
- 评论数
- 点赞数
- 粉丝数

## 2. 适用对象

适合业务同事、运营同事、数据整理同事使用。

使用者不需要会代码，只需要双击 exe、填写公司内部授权提供的微博 Cookie，然后粘贴微博链接查询。

## 3. 使用方式

1. 下载 `release/微博信息批量查询.exe`。
2. 双击打开 `微博信息批量查询.exe`。
3. 点击右上角“Cookie 设置”。
4. 粘贴公司提供的微博 Cookie。
5. 点击“保存 Cookie”。
6. 把微博链接粘贴到输入框，每行一个。
7. 点击“批量查询”。
8. 根据需要点击“复制表格”“复制数据”“复制互动量”，或点击表头下方的单列复制按钮。

## 4. 输入格式

每行一个微博链接，例如：

```text
https://weibo.com/7524946997/5263319904816444
https://weibo.com/5747757876/5263316721077979
https://weibo.com/5235744929/Qqz6ClzRG
```

## 5. 查询限制

- 单次最多查询 50 条链接。
- 每条请求之间会有 0.5s-1s 延迟，查询时请耐心等待。
- 工具使用低并发查询，避免高频请求。
- 部分微博可能因为权限不可见、Cookie 失效、接口限制、网络问题或链接格式错误导致失败。
- 失败行会保留在结果表格中，方便和原始输入顺序对应。

## 6. 复制功能说明

- 复制表格：复制完整表格，包含表头，适合直接粘贴到 Excel / WPS。
- 复制数据：复制完整数据行，不包含表头。
- 复制互动量：只复制 `转发数 | 评论数 | 点赞数` 三列，不包含表头。
- 表头复制：可以复制单独一列，例如发布日期、发布内容、账号名称、发布链接、粉丝数。
- 复制后可直接粘贴到 Excel / WPS。

互动量复制顺序固定为：

```text
转发数 | 评论数 | 点赞数
```

复制互动量的 TSV 示例：

```text
139	299	854
190	280	1250
132	216	985
```

完整表格字段顺序固定为：

```text
发布日期 | 发布内容 | 账号名称 | 发布链接 | 转发数 | 评论数 | 点赞数 | 粉丝数
```

## 7. Cookie 说明

- Cookie 由公司内部授权提供。
- Cookie 只保存在本机 exe 同目录的 `config.json`。
- Cookie 不会上传到外部服务器。
- 不要把 Cookie 发到外部，也不要写入文档、截图或聊天记录。
- Cookie 失效后，重新点击“Cookie 设置”更新即可。
- 源码、README、`.env.example`、打包文件都不写入真实 Cookie。

生产环境示例：

```text
微博信息批量查询.exe
config.json
```

## 8. 合规说明

本工具仅用于公司内部授权范围内的少量微博链接信息整理。请勿用于绕过平台限制、批量高频抓取、采集非公开信息、个人信息画像、数据售卖或任何违反平台规则及法律法规的用途。

本工具不会抓取评论列表、点赞用户列表、转发用户列表、粉丝列表、关注列表，也不会保存额外用户资料或用于个人画像。

## 9. 常见问题

Q：为什么查询失败？  
A：可能是 Cookie 失效、微博权限不可见、链接格式错误或网络问题。

Q：为什么粉丝数显示未获取？  
A：部分微博详情接口不返回粉丝数字段，工具只能在公开可访问范围内尝试获取。

Q：为什么查询比较慢？  
A：工具设置了低并发和 0.5s-1s 延迟，用于避免高频请求。

Q：可以一次查很多吗？  
A：单次最多 50 条，请分批处理。

Q：复制到 Excel / WPS 后没有分列怎么办？  
A：请使用工具内的“复制表格”“复制数据”或“复制互动量”按钮，它们使用 tab 分隔，粘贴后会自动分列。
