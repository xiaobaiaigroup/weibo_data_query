# 需求说明

## 1. 项目目标

创建一个“微博信息批量查询工具”。用户粘贴多条微博链接后，系统按输入顺序查询并展示每条微博的核心公开数据，同时提供适合 Excel / WPS 的整表复制、数据复制、互动量复制和单列复制。

项目支持打包为 Windows 桌面应用，供业务同事双击运行，不要求同事安装 Node.js 或执行 npm 命令。

合规提示：本工具仅用于公司内部授权范围内的少量微博链接信息整理。请勿用于绕过平台限制、批量高频抓取、采集非公开信息、个人信息画像、数据售卖或任何违反平台规则及法律法规的用途。

## 2. 页面功能

- 顶部标题：微博信息批量查询。
- 右上角：Cookie 设置。
- 批量输入：textarea 支持每行一个微博链接，自动忽略空行。
- 一键粘贴：读取剪贴板文本并填入 textarea。
- 操作按钮：批量查询、清空、复制表格、复制数据。
- 状态统计：共 X 条、成功 X 条、失败 X 条。
- 结果表格：横向滚动，固定列顺序展示。
- 表头复制：发布日期、发布内容、账号名称、发布链接、粉丝数支持单列复制。
- 互动量复制：转发数、评论数、点赞数三列合并为一个“复制互动量”按钮。
- 底部合规提示：桌面应用和网页版本都显示。
- Electron 右键菜单：textarea 支持剪切、复制、粘贴、全选。

## 3. 字段说明

表格列顺序固定为：

```text
发布日期 | 发布内容 | 账号名称 | 发布链接 | 转发数 | 评论数 | 点赞数 | 粉丝数
```

| 字段 | 说明 |
| --- | --- |
| 发布日期 | 微博发布时间 |
| 发布内容 | 微博正文，失败时为错误原因 |
| 账号名称 | 发布微博的账号名称 |
| 发布链接 | 规范化后的微博链接，失败时保留原始输入链接 |
| 转发数 | 转发数量 |
| 评论数 | 评论数量 |
| 点赞数 | 点赞数量 |
| 粉丝数 | 当前微博作者的公开粉丝数统计 |

粉丝数优先从微博详情响应里已有的 `user.followers_count`、`followersCount`、`followers_count_str`、`fans_count`、`fansCount` 或类似公开统计字段读取。如果没有该字段，则尝试从当前微博详情页公开 HTML / 页面初始状态中解析作者卡片展示值；仍取不到时，会针对当前微博作者 uid 请求公开 profile info 接口，并且只读取粉丝数字段。示例 `42.1万 粉丝` 会转换为 `421000`。如果仍取不到，则返回“未获取”。

## 4. 桌面应用使用流程

1. 双击 `微博信息批量查询.exe`。
2. Electron 自动启动本地 Express 服务。
3. 桌面窗口自动打开页面。
4. 如未配置 Cookie，页面提示：未配置微博 Cookie，请点击右上角“Cookie 设置”填写后再查询。
5. 用户点击“Cookie 设置”，粘贴公司提供的微博 Cookie。
6. 点击“保存 Cookie”。
7. 粘贴微博链接，每行一个，单次最多 50 条。
8. 也可以点击“一键粘贴”读取剪贴板内容到输入框。
9. 点击“批量查询”。
10. 查看表格并按需复制整表、完整数据、互动量或某一整列。

## 5. Cookie 设置功能说明

Cookie 设置弹窗包含：

- 标题：微博 Cookie 设置。
- 说明：Cookie 只会保存在本机配置文件中，不会写入源码。
- textarea：用于粘贴 Cookie。
- 按钮：保存 Cookie、清空 Cookie、关闭。
- 状态：如果已配置 Cookie，只显示遮罩后的 Cookie，不展示完整明文。

Cookie 只保存在 exe 同目录的 `config.json`。API 不返回完整 Cookie。

## 6. config.json 配置说明

生产环境中，Cookie 保存到 exe 同目录的 `config.json`：

```text
微博信息批量查询.exe
config.json
```

`config.json` 不打包进 exe 内部，不写入 asar 内部，文件不存在时自动创建。

## 7. API 说明

微博批量查询：

```http
POST /api/weibo/batch
```

配置状态：

```http
GET /api/config/status
```

保存 Cookie：

```http
POST /api/config/cookie
```

清空 Cookie：

```http
DELETE /api/config/cookie
```

批量查询超过 50 条时，后端返回：

```json
{
  "success": false,
  "message": "单次最多查询 50 条，请分批处理"
}
```

## 8. 复制格式说明

“复制表格”输出 TSV，包含表头和所有结果行：

```text
发布日期	发布内容	账号名称	发布链接	转发数	评论数	点赞数	粉丝数
```

“复制数据”只复制数据行，不包含表头，列顺序同上。

“复制互动量”只复制三列，不包含表头，顺序固定为：

```text
转发数	评论数	点赞数
```

单列复制不包含表头，每一行一个值。发布日期、发布内容、账号名称、发布链接、粉丝数支持单列复制；失败行保留空值，避免和其它列错位。

## 9. 批量查询安全限制

- 单次最多 50 条链接。
- 前端超过 50 条时不发起请求。
- 后端超过 50 条时返回 400。
- 后端并发限制为 2。
- 每条请求前增加 500ms-1000ms 随机延迟。
- 单条失败最多重试 1 次。
- 同一批量任务中，同一个作者 uid 的粉丝数补充请求只请求一次并缓存。
- 最终 `data` 数组顺序与用户输入顺序一致。
- 前端 loading 时禁用批量查询按钮，避免重复提交。

## 10. 信息采集范围限制

本工具只保留：

```text
发布日期、发布内容、账号名称、发布链接、转发数、评论数、点赞数、粉丝数
```

不抓取评论列表、点赞用户列表、转发用户列表、粉丝列表、关注列表、用户主页详情、用户额外个人资料、非公开信息或任何用于个人画像的数据。

## 11. 打包说明

Electron 开发运行：

```bash
npm run electron:dev
```

打包：

```bash
npm run dist
```

输出 exe：

```text
release/微博信息批量查询.exe
```

## 13. 已知限制

- 微博接口和页面结构可能变化，变化后可能返回“接口返回结构异常”或部分字段“未获取”。
- 部分微博需要登录、权限不可见或 Cookie 已失效。
- 粉丝数取不到时显示“未获取”。
- 本项目不实现验证码绕过、登录绕过或反爬绕过。
- 当前支持 `https://weibo.com/{uid}/{mid}` 和 `https://weibo.com/{uid}/{base62}` 形式。
